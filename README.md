# CodeAlpha Task 2 - Exploratory Data Analysis

## Internship
CodeAlpha Data Analytics Internship

## Task
Exploratory Data Analysis (EDA)

## Project Description
This project performs Exploratory Data Analysis on a books dataset collected from a public website.

## Analysis Performed
- Dataset structure and dimensions
- Data types
- Missing value analysis
- Duplicate detection
- Descriptive statistics
- Price distribution
- Rating distribution
- Outlier detection
- Price comparison across ratings
- Correlation analysis
- ANOVA statistical analysis
- Data quality analysis
- Data visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Google Colab

## Files
- `CodeAlpha_Task2_EDA.ipynb` - Complete EDA notebook
- `CodeAlpha_Task2_EDA_Summary.csv` - EDA summary
- `CodeAlpha_Task1_Books_Dataset.csv` - Dataset used for analysis
